# Dashboard Surdin Integrity

Landing page for the PPST Integrity 2026 portal at Universiti Malaysia Sabah.

## Files

- `Index.html` - The static landing page and its inline assets/data.
- `vercel.json` - Routes the Vercel root URL to `Index.html`.

## Run locally

Open `Index.html` directly in a browser, or serve the folder with any static file server.

## Deploy with Vercel

Import this GitHub repository into Vercel. No build command or framework preset is required. The included `vercel.json` serves the page at the root URL.

The featured video and OneDrive links require access through a UMS account with the appropriate permissions.
